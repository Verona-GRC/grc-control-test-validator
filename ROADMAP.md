# Project Roadmap

## GRC Control Test Validator

This roadmap outlines the planned development of the GRC Control Test Validator from a basic control-testing prototype into a more capable GRC assurance tool.

## Phase 1 – Working Prototype (Completed)

- Develop a Python-based control testing script.
- Create fictional deployment and approval records.
- Define testing criteria for production deployment approvals.
- Implement Pass, Fail and Inconclusive classifications.
- Generate a structured CSV results report.
- Document the control test plan, testing methodology and audit findings.

## Phase 2 – Improved Testing and Reporting

- Introduce additional evidence completeness checks.
- Improve exception identification and tracking.
- Support clearer audit observations and recommendations.
- Improve the structure and usability of generated reports.
- Expand testing scenarios and validation rules.

## Phase 3 – Expanded Control Coverage

- Introduce additional security and GRC control tests.
- Develop configurable testing criteria.
- Support testing across multiple control environments.
- Improve traceability between control requirements, evidence and test results.

## Phase 4 – AI-Assisted GRC Capabilities

- Explore AI-assisted evidence interpretation.
- Support the identification of potential control gaps.
- Generate draft audit observations and recommendations.
- Introduce human review and approval before finalising AI-assisted outputs.

## Phase 5 – Source-System Evidence Integration

- Explore integration with relevant source systems.
- Retrieve evidence directly from authorised systems where technically feasible.
- Improve evidence traceability and auditability.
- Reduce reliance on manually prepared evidence files.

## Development Principles

The project will prioritise:

- Evidence-based testing.
- Consistent and repeatable results.
- Clear explanations of exceptions.
- Human oversight and professional judgement.
- Practical application of audit and GRC principles.
- Responsible use of AI and automation.

## Current Status

The project is currently a working, rule-based prototype using fictional CSV data. Future phases are planned enhancements and have not yet been implemented.
